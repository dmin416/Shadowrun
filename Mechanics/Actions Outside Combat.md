## When to roll

Dice complement roleplay; they do not replace it. Use a Social or Perception Test at the end of a scene, or to skip a dull one. Apply GM modifiers for how well the point was made. Do not dice every door or greeting.

## Perception

### Pool and Limit

```
Perception + Intuition [Mental]
```

Success vs threshold (or vs opponent if they hide) = you notice something subtle or important. **Net hits** = how much detail.

Vision Perception Tests also use combat **Visibility / Light** Environmental Modifiers (Combat ~p.173). Multiple people looking for the same thing: Teamwork Test ([Dice and Tests](Dice%20and%20Tests.md)).

### Observe in Detail

Simple Action (combat action list). You can also call for Perception when the GM asks. Immediately obvious facts need no roll (GM discretion; enhancements matter). Example: you see someone running at you with something in hand; ID friend/foe or identify the object may need Observe in Detail.

### Perception Test Modifiers

| Situation | Dice Pool Modifier |
| --- | --- |
| Perceiver is distracted | -2 |
| Perceiver is specifically looking/listening for it | +3 |
| Object/sound not in immediate vicinity | -2 |
| Object/sound far away | -3 |
| Object/sound stands out in some way | +2 |
| Interfering sight/odor/sound | -2 |
| Perceiver has active enhancements | +(Rating) |
| Visibility and Light | Environmental Factors (Combat) |

### Perception Thresholds

| Item/Event Is | Threshold | Examples |
| --- | --- | --- |
| Obvious/Large/Loud | 1 | Neon sign, running crowd, yelling, gunfire |
| Normal | 2 | Street sign, pedestrian, conversation, silenced gunfire |
| Obscured/Small/Muffled | 3 | Item under table, contact lens, whispering |
| Hidden/Micro/Silent | 4 | Secret door, needle in haystack, subvocal speech |

## Stealth

Opposed Test: seeker rolls **Perception + Intuition** (apply Perception mods). Hider rolls a Stealth-group skill (typically **Sneaking + Agility**). GM may let the seeker swap Perception for a Stealth skill at no penalty (e.g. assassin uses Sneaking + Intuition to spot you in a crowd).

## Disguise and Impersonation

| Step | Test | Effect |
| --- | --- | --- |
| Apply disguise | Disguise + Intuition [Mental] | Hits = threshold to see through later |
| Improve / stand alone | Impersonation + Charisma [Social] | With disguise: add hits to that threshold. Alone (voice, etc.): standard Opposed Test |
| Spot fake | Perception (+ Intuition) vs threshold / Opposed | Meet or beat quality → exposed |

Disguise Kit: Build & Repair Extended Test; add **half** that Extended threshold (max +4) as dice to the Disguise Test.

## Social skills

Most influence skills link to **Charisma** and use the **Social** Limit. Crowds: oppose the **leader**; leader gets **+2** dice and Limit +1 per person backing them ("ace in the hole").

### Social Skill Tests

| Character Roll | Target Roll |
| --- | --- |
| Con + Charisma [Social] | Con + Charisma [Social] |
| Etiquette + Charisma [Social] | Perception + Charisma [Social] |
| Impersonation + Charisma [Social] | Perception + Intuition [Mental] |
| Intimidation + Charisma [Social] | Charisma + Willpower |
| Leadership + Charisma [Social] | Leadership + Willpower [Social] |
| Negotiation + Charisma [Social] | Negotiation + Charisma [Social] |
| Performance + Charisma [Social] | Charisma + Willpower |

**Performance** can also be a Simple Test (hits = artistry). To distract / sweep up a target, use Social Modifiers and Charisma + Willpower Opposed.

### Etiquette

Blend in / ease suspicion: Etiquette + Charisma [Social] vs Perception + Charisma [Social]. Any net hits → accepted. **3+ net hits** → NPC attitude moves **one step better** on the attitude ladder.

Social blunder safety net: Etiquette vs threshold = severity (Success thresholds, Concepts). Success = character recovers.

| Glitch | Effect |
| --- | --- |
| Glitch | Temporary annoyance; often -2 on next social test |
| Critical glitch | Lasting gaffe; NPC may move one step toward Enemy |

### Leadership (Complex Action when accepted as superior)

Simple Leadership + Charisma [Social]; effect depends on choice:

| Mode | Effect |
| --- | --- |
| Command | Target resists Leadership + Willpower [Social]. Net hits = Combat Turns they accept you as leader. Fails permanently on that target if you failed before |
| Direct | Hits as Teamwork for one subordinate's skill or Composure on/before their next Action Phase |
| Inspire | Hits as Teamwork for subordinates' Surprise Tests this Combat Turn |
| Rally | +1 Initiative Score per 2 hits for subordinates this Combat Turn |

### Instruction

Teacher needs the skill at **Rating 4+**; can teach up to their **Instruction** rating. Instruction + Charisma [Social]; each hit shortens student improvement time by **1 day** (Character Advancement). Spells / forms / rituals use section-specific Instruction rules.

## Survival

24 hours or more exposed to extreme outdoor conditions (including hostile urban streets) → make a **daily Survival + Willpower [Mental]** Test vs the terrain threshold below. Fail → take **Stun DV = 2 x threshold**; this Stun cannot be healed until you get a good night's sleep **without** having to make a Survival Test that day. If the Stun Condition Monitor overflows before then, damage becomes Physical and keeps accruing daily until rescued, relieved, or dead.

### Survival Test Table

| Wilderness Terrain | Threshold |
| --- | --- |
| Mild (forest, plains, urban) | 1 |
| Moderate (foothills, jungle, swamp) | 2 |
| Tough (desert, high mountains) | 3 |
| Extreme (Arctic, Antarctic) | 5+ |

| Situation | Pool Modifier |
| --- | --- |
| Camping/survival gear on hand | +2 |
| No food or water | -2 |
| Heat/climate control available | +1 |
| Inappropriate clothing/armor | -1 to -4 |
| Extended travel or exertion | -1 to -4 |
| Toxic terrain | -2 to -4 |
| Character injured | -Wound Modifier |

| Weather | Pool Modifier |
| --- | --- |
| Poor | -1 |
| Terrible | -2 |
| Extreme | -4 |

## Structured Con (*Cutting Aces*)

**Verified from:** `Cutting Aces Condensed.md`

Track **Intel Rating** and **Prop Rating** (start 0). Long Con steps with intervals take at least a full day. GM modifiers for cleverness.

### Phase One: Preparation

| Step | Long / Short | Test | Effect |
| --- | --- | --- | --- |
| Legwork | Optional, Long | Contact legwork (*SR5* p. 387) | +Intel |
| Matrix Searches | Optional, Long | Opposed Matrix Search | +Intel (GM sets target pool) |
| Scouting the Target | Mandatory, Both | Perception + Intuition vs Perception + Intuition | Net hits +/- Intel |
| Evaluating the Target | Optional, Long | Psychology (Profiling) + Logic [Intel] vs Intel (needs Intel > 0) | +Intel |
| Prop-Building | Optional, Both | Extended Forgery or Artisan + Agility; thresh = 2 x Prop; 1 day interval | Sets Prop (early stop: Prop = hits/2) |
| Prop Acquisition | Optional, Both | Buy or steal; default esoteric Avail = 3 x Prop; Price = Avail x 1,000¥ | Sets Prop |

### Phase Two: Engage

| Step | Long / Short | Test | Effect |
| --- | --- | --- | --- |
| Set the Hook | Mandatory, Both | Con + Cha (+ Prop) vs higher of Judge Intentions or Con + Intuition (- Intel) | Win: mark buys it. Tie Long: Reinforce mandatory. Tie Short: target wins |
| Reinforce the Lie | Optional, Long | Con + Cha vs Judge Intentions (old Intel/Prop void) | Win: still bought. Lose/tie: mark realizes |

Re-enter Phase Two whenever discovery threatens.

### Phase Three: Getaway

| Step | Long / Short | Test | Effect |
| --- | --- | --- | --- |
| Graceful Exit | Optional, Both | Con + Cha vs Judge Intentions or Con + Intuition | Win: mark still believes after you vanish. No exit: mark knows something wrong |

### Expanded Intimidation (*Cutting Aces*)

May substitute for Negotiation for one-sided gains: each net hit = something with no reciprocity. No priced offer: each net hit = **250¥ value** or one truthful detail. Glitch: lasting grudge. Critical glitch: elaborate long-term enemy alliance.

## Social maneuvers (*Cutting Aces*, optional)

Default: **-4 dice** unless noted; Free Action plus any listed action.

| Maneuver | Test | Effect |
| --- | --- | --- |
| Charming Performance | Performance; 1+ hits | Increase NPC attitude one step |
| Drill Sergeant | Intimidate + Cha | Target -2 next Leadership + Wil vs your commands |
| Faux Pas | Etiquette + Cha | Target -2 Social next turn |
| Hustling the Mark | Con + Cha at -6 | Fail: +2 next Con or Negotiation vs same target |
| Informed Opinion | Relevant Knowledge | Add hits as dice to Social limit this encounter |
| Misdirection | Con + Cha; 1+ hits | Target -4 Perception until next action |
| Motivational Teacher | Leadership + Cha | +2 on your next Instruction |
| Peer Tutoring | Instruction + Cha (all) | Ranks 1-3 training speedup if all hit threshold |
| Pressing Flesh | Etiquette + Cha (touch) | +2 Palming same person same Action Phase |
| Rub It In | Negotiation + Cha + leverage | Double usual +2 blackmail chip (to +4) |
| Saving Face | After failed Social: Etiquette -4 | Success: retry that Social at no penalty |
| Shake It | Con (Seduction) + Cha | Observers +2 Perception vs you, -2 vs others nearby |
| Wooden Gun | Palming + Agi vs Perception + Int | +2 Con or Intimidate to imply ready weapon |
| Zanshin | Judge Intentions at -2 | 1 hit: Close Combat ranks? 2: which highest? 3: training level band |
