# Actions Outside Combat

Most non-fight scenes still use Attribute + Skill ± mods vs thresholds or opposed rolls. See [Dice and Tests](Dice%20and%20Tests.md).

## Perception

- **Perception + Intuition** to notice clues, ambushes, astral/physical oddities.
- Thresholds rise with concealment, distance, distraction.
- Sensors, drones, spells, and spirits change what you can detect.

## Stealth & intrusion

| Task | Typical pool |
| --- | --- |
| Sneak past guards | Sneaking + Agility vs Perception + Intuition |
| Pick lock / bypass maglock | Locksmith / Hardware + Agility/Logic |
| Disguise / impersonate | Disguise / Con + Intuition/Charisma |
| Palming / pickpocket | Palming + Agility opposed |

Wireless world: cameras, SIN scanners, and PAN noise matter as much as footsteps.

## Social actions

| Task | Skill |
| --- | --- |
| Negotiate pay | Negotiation + Charisma |
| Lie convincingly | Con + Charisma |
| Scare | Intimidation + Charisma |
| Fit in / etiquette | Etiquette + Charisma |
| Lead a team / NPC | Leadership + Charisma |

Social Limit caps hits. Appearance, reputation, racial prejudice, and context modify dice.

## Investigation & tech

- **Computer / Software / Hardware** for devices
- **Tracking**, **Navigation**, **Survival** for physical hunts
- **Chemistry**, **First Aid**, **Medicine** for labs and clinics
- Extended tests for long research or builds

## Travel & downtime

- Lifestyle covers day-to-day needs - [Housing and Lifestyle](Housing%20and%20Lifestyle.md)
- Legwork: contacts, Matrix search, street gossip
- Training and healing between runs - [Healing and Injuries](Healing%20and%20Injuries.md), Karma advancement

## When to roll vs roleplay

Roll when failure is interesting or uncertain. Don’t dice every door open or every hello - save pools for pressure.
