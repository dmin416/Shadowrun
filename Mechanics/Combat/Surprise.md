## When it applies

| Case | Rule |
| --- | --- |
| Start of fight | Common (ambush, open door into guns, etc.) |
| Mid-fight | New force enters unexpectedly → everyone (old + new) may retest |
| Who | Characters and critters. Not barriers, foci, programs, IC, etc. |
| Per character | You can be surprised by one foe and not another |

---

## Perception prep (optional)

GM may make a **secret Perception Test**. Success → character is **alerted** (+3 Surprise). Combat Sense spell/adept power: always get a Perception chance (can still fail Surprise).

---

## Surprise Test

```
Reaction + Intuition (3)   [no Limit]
```

| Modifier | When |
| --- | --- |
| +3 | Alerted (Perception or similar) |
| +6 | Planning an **ambush** and delaying while waiting |

| Result | Effect |
| --- | --- |
| Success (≥3 hits) | Act normally |
| Failure | Initiative Score **-10** (at Init roll, or immediately if mid-Turn); **surprised** until your next Action Phase |
| Edge | Spend Edge to **avoid surprise** (regain Defense); **still** take the -10 Init |
| Glitch | Still act, but startle (drop item, bump, etc.; GM) |
| Critical glitch | Completely stunned: no act on first Action Phase. Still take -10 for failed Surprise. If also joining mid-fight, add another -10 for late entry |

---

## Ambushing

| Rule | Detail |
| --- | --- |
| Bonus | +6 Surprise for ambushers who delay and wait |
| Auto not surprised? | Only if aware of prey's movement (open ground watch). If waiting blindly (anyone who opens the door), still +6 but **must** roll Surprise too |
| Higher Init | Ambushed PC with higher Score than ambushers can still act first |

---

## Effects of being surprised

| Can | Cannot |
| --- | --- |
| Drop prone, ready a weapon, other actions **not** aimed at unsurprised foes (Effects of Surprise explicitly allows these) | Attack unsurprised characters |
| | Defend / Dodge / Full Defense vs attacks from unsurprised characters |
| | React to allies' warnings about those foes |
| | Take Cover (Simple text: not if surprised) |
| | Interrupts before you are no longer surprised |

No Defense Test vs attackers you are surprised by (treat as unaware). Edge can buy Defense back (Init -10 remains).

**Note:** Generic Drop Prone Free Action text says "not if surprised," but Effects of Surprise lists dropping prone as allowed. Prefer Effects of Surprise for the surprise state.
---

## Mid-combat surprise

New unexpected participants → Surprise Tests for all. Adjust Scores; surprised get no Defense this Phase. Newcomers also apply mid-fight Init: -10 per Pass already done ([Initiative](Initiative.md)).
