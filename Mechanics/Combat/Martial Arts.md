## Learning martial arts

| Item | Learning time | Karma | Instruction cost |
| --- | --- | --- | --- |
| New technique (known style) | 2 weeks | 5 | 1,500¥ |
| New style + first technique | 1 month | 7 (style) + 5 (technique) | 2,500¥ |

| Rule | Detail |
| --- | --- |
| Chargen | One style only; up to **5** techniques total in that style for **27** Karma |
| After chargen | Learn more techniques in a style, or new styles (each new style = 1 month + 7 Karma includes first technique) |
| Multiple styles | Allowed; duplicate technique bonuses stack only to **+2** bonus or **-2** modifier reduction total |
| Specialization | Style as skill specialization: **7** Karma; +2 when using that style |

Techniques only via a martial art style or **One Trick Pony** quality (RnG).

## Techniques (effects)

When a Called Shot appears as a technique: if normally available to all, reduce Called Shot modifier by **1** for that shot; if it requires MA training, the character may use it but gets **no** modifier reduction unless the technique says otherwise.

### Multiple Attacks and martial arts

Multiple Attack Free Action **cannot** combine with techniques needing their own action (Counterstrike, Iaijutsu, Flying Kick, Throw Person). Can combine with modifier/DV techniques and some Called Shot techniques (Pin, Entanglement). Multiple Opponent Combat is designed for Multiple Attacks.

## Cybernetics and martial arts

| Topic | Rule |
| --- | --- |
| Cyber limbs | Individual limb/hand Strength for subduing (arm, hand, leg chokes) |
| Hand razors / spurs | No cyber weapon spec bonus on throw, grapple, subdue, disarm; cyber weapons can be **broken** (Called Shot reduces AP by 1 per hit; retractable may fail to retract); repair = Logic + Cybertechnology (10, 1 hour) Extended, cost 1/10 cyberware price |
| Skillwires | Skill rating OK; **cannot** use MA techniques without learning style/technique separately |

## Magic and martial arts

| Topic | Rule |
| --- | --- |
| Touch spells in grapple | Opponent resists only; no Defense vs Touch Attack |
| Magic Fingers / finesse | No Superior Position, Reach, or extra DV from techniques; GM may penalize finesse techniques (Dim Mak, etc.) |
| Adept power overlap | Light Body supersedes Rolling Cloud / Leaping Mantis; Wall Running supersedes Monkey Climb; power off = technique still works |

---

## Electricity damage and martial arts

Shock glove / stun baton: choose normal weapon damage (techniques apply) **or** shock damage (no net hits / technique DV boost). Grapple/clinch + touch contact: Free Action shock if GM agrees weapon touches; else Simple. Target -3 Defense; tied roll = hit (touch-only). Shock damage ignores net hits and techniques.
