# Action Economy

On your action phase you may take:

| Package | Typical contents |
| --- | --- |
| **One Complex Action** | Attack, Sprint, Cast Spell, Matrix action that lists Complex, etc. |
| **or Two Simple Actions** | Fire SA/BF gun, Take Aim, Reload (some), Observe, Call Shot setup, etc. |
| **plus Free Actions** | Speak briefly, drop prone, change device mode, gesture — GM limits spam |

You also get **Movement** each Combat Turn (not usually an action) — see [Movement](Movement.md).

## Free Actions (examples)

- Speak a short phrase
- Drop an object
- Fall prone
- Switch wireless on/off (simple devices)
- Eject smartgun clip (with proper gear)

## Simple Actions (examples)

- Fire a weapon in **SS / SA / BF** mode (as allowed)
- Take Aim (+1 Accuracy / dice benefits per rules)
- Observe in Detail (Perception)
- Insert clip / some reload types
- Activate focus
- Call a shot (declaration — combined with attack rules)

## Complex Actions (examples)

- Fire **Full Auto**
- Melee Attack
- Reload some weapons
- Cast spell / summon
- Many Matrix actions
- Sprint
- Use Complex skill applications

## Interrupt Actions

Cost Initiative Score (often −5 or −10) to react off-turn:

- **Full Defense**
- **Dodge / Block / Parry** variants
- **Intercept** melee
- Matrix / rigger interrupts as listed

Track Initiative carefully when interrupts fire.

## Delay

You may delay to act later in the pass / turn (subject to Core delay rules) to coordinate with teammates.
