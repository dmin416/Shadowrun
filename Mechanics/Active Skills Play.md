## Schema

| Token | Meaning |
| --- | --- |
| Pool | Skill Rating + Attribute (± mods) |
| Limit | Usually Mental / Physical / Social, or Accuracy / Handling / etc. |
| Default | Untrained: Attribute − 1 (if Default Yes) |
| Spec | +2 DP when specialization applies |

```
Skill + Attribute [Limit] ± modifiers
```

GM picks skill + Attr for the situation; linked Attr is the default pairing.

---

## Defaulting

| Rule | Detail |
| --- | --- |
| Default Yes | Pool = linked Attr − 1 (no skill dice) |
| Default No | Cannot attempt without the skill |
| List | [Character Creation/Skills](Character%20Creation/Skills.md) Cannot default table |

---

## Specializations and groups

| Rule | Detail |
| --- | --- |
| Spec | +2 when the narrow case applies |
| Group | Rating applies to every skill in the group |
| Break group | Raising one skill alone → group splits to individual skills at former rating ([Advancement](Advancement.md)) |
| Re-form | All skills in group equal → may buy as group again |

## Building & Repairing

Extended Test; GM sets threshold + interval (Extended Test tables, Dice and Tests / Core p.48). May require tools/facility. New designs need appropriate Knowledge skills.

### Build/Repair modifiers

| Situation | Pool Modifier |
| --- | --- |
| Conditions — Distracting | −1 |
| Conditions — Poor | −2 |
| Conditions — Bad | −3 |
| Conditions — Terrible | −4 |
| Conditions — Superior | +1 |
| Tools/Parts — Inadequate | −2 |
| Tools/Parts — Unavailable | −4 or not allowed |
| Tools/Parts — Superior | +1 or more |
| Plans available | +1 |
| Plans AR-enhanced | +2 |
| Memory only, Logic 5+ | +0 |
| Memory only, Logic 1–4 | −(5 − Logic) |

Used by: Armorer, Hardware, Mechanics (Aero/Auto/Industrial/Nautical), Cybertechnology, Biotechnology (as applicable), Disguise kit prep, etc.

## Forgery (play)

| Step | Rule |
| --- | --- |
| Create | Forgery + Logic [Physical or Mental]; Build/Repair mods; GM interval |
| Quality | Hits = quality (spot threshold) |
| Spot | Perception + Intuition [Mental] or Forgery + Intuition [Mental] vs quality |
| Data forgeries | Look OK; acting as real (SIN check, transfer ¥) fails scrutiny |
