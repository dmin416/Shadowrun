## Procedure

1. Earn Karma ([Gig Rewards](Gig%20Rewards.md)).
2. Schedule **downtime** for training (except Edge, and except paying for spells/forms/qualities/grades once rules allow).
3. Complete training time (interruptible; resume soon or lose progress — GM call).
4. Pay Karma for the **new** Rating / purchase when training finishes.
5. Recalculate limits, Initiative, Condition Monitors, etc. ([Finishing Touches](Character%20Creation/Finishing%20Touches.md) Final Calculations).

## Character Improvement (Karma)

| Improvement | Karma Cost |
| --- | --- |
| Attribute (Mental / Physical / Magic / Resonance) | new Rating × **5** |
| Active skill | new Rating × **2** |
| Active skill group | new Rating × **5** |
| Knowledge / Language skill | new Rating × **1** |
| New Knowledge / Language skill (Rating 1) | **1** |
| New specialization (Active / Knowledge / Language) | **7** |
| New spell / ritual / preparation | **5** |
| New complex form | **4** |
| New Positive quality | listed cost × **2** |
| Remove a Negative quality | listed bonus Karma × **2** |
| New initiate grade | **10 + (Grade × 3)** |
| New submersion grade | **10 + (Grade × 3)** |

**Edge** uses the Attribute cost (new Rating × 5) and needs **no** training time.

## Training Rate

| Improvement | Rate |
| --- | --- |
| Attribute (Mental, Physical, Magic, Resonance) | new Rating × **1 week** |
| Edge | **None** |
| Skill Rating 1–4 | new Rating × **1 day** |
| Skill Rating 5–8 | new Rating × **1 week** |
| Skill Rating 9–13 | new Rating × **2 weeks** |
| Skill group | new Rating × **2 weeks** |
| New specialization | **1 month** (dedicated; nothing else at the same time) |

### Downtime limits

| What | Cap per downtime |
| --- | --- |
| One Mental **and** one Physical attribute, **or** one attribute **and** one skill | Yes |
| Attribute raise on same Attr just implanted/aug’d that downtime | **No** — recovery/getting-used-to only; train next downtime |
| Attribute Rating increase | Max **+2** Ratings in one downtime |
| Active / Knowledge / Language skill | Max **+3** Ratings total across skills this downtime |
| Skill group | Max **+1** Rating; cannot train other attrs/skills while raising a group |
| Skills-only focus | Up to **Logic ÷ 2** (round up) skills at once |
| Dependents quality | Training / long projects × **1.5** time |

Attribute training time **cannot** be reduced. Skill training with an instructor: **−25%** time (round down). See Instruction in [Actions Outside Combat](Actions%20Outside%20Combat.md).

## Qualities in play

| Action | Cost |
| --- | --- |
| Buy Positive quality | Listed Karma × **2** |
| Buy off Negative quality | Listed bonus × **2** + meet requirements + GM OK |

GM may **award** Positive or Negative qualities from campaign events without the ×2 buy (still can buy off Negatives later at ×2).
