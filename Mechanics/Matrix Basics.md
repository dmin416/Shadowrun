# Matrix Basics

The Matrix is the world’s network. Deckers use **cyberdecks**; technomancers use a **living persona**.

## Persona attributes

| Attribute | Role |
| --- | --- |
| **Attack** | Cybercombat offense |
| **Sleaze** | Stealth / illegal quiet actions |
| **Data Processing** | Speed / many Matrix limits |
| **Firewall** | Defense |

Commlinks are weaker; decks swap attribute arrays. Noise and distance impose penalties.

## Marks & hosts

- Illegal actions place **marks** on targets (1–3).
- More marks unlock more powerful actions (file edit, reboot, dumpshock, etc.).
- **Hosts** are rated systems (corp sites, security) with their own attributes and IC.

## Action timing

Matrix actions are Free / Simple / Complex like meat actions and share Initiative if you’re in the same fight. VR users often get better Initiative Dice (hot-sim riskier).

## Overwatch & GOD

Illegal actions build **Overwatch Score**. When it hits the limit, **GOD** convergence dumps and traces you — bad news.

## Cybercombat

Opposed Attack vs Firewall-type defenses; damage to Matrix Condition Monitor; biofeedback can spill to Stun/Physical for VR users.

## Technomancers

- Complex forms instead of many programs
- Sprites analog to spirits
- Fading instead of drain
- Resonance abilities; no deck required (but living persona has limits)

Deep rules: Core Matrix chapter; *Data Trails*, *Kill Code* for advanced play.
