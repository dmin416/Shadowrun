## Overview

CFD rewrites personality via **infected nanites** (and linked Matrix entities). Non-biological; infects metahumans, electronics, and nanofabricated materials. **No canon full cure** at publication; player infection only with table buy-in.

### In-universe progression (soft)

| Stage | Effect |
| --- | --- |
| Initial | Contact with infected nanites; onset scales with nanite volume in host |
| Stage 1 | Headaches, memory faults, motor problems, emotion swings, sensory hypersensitivity |
| Stage 2 (Fragmentation) | Blackouts; personality fragments (PFs) take control; sleep deprivation accelerates overwrite |
| Stage 3 | Full DID-like switching; PFs aware of all activity |
| Stage 4 | Original personality subjugated; PF in full-time control |

Awakened/Emerged hosts resist longer; larger mammals/paranimals often keep paranormal abilities.

## Hard rules: Nanite Volume (NV) and MEC

| Rating | Meaning |
| --- | --- |
| **Nanite Volume (NV)** | Cumulative infected nanites in host (see table) |
| **Matrix Entity Concentration (MEC)** | GM-set cohesion of dominant Matrix personality(s). High MEC = faster overwrite; low/multiple = amalgam / longer switching |

### Nanite Volume sources (cumulative)

| Source | NV |
| --- | --- |
| Nanohive | + Rating |
| Nanite system | + half Rating |
| Genetech | +1 per 2 genetic modifications |

**Reproduction:** +1 NV/week if head case eats (soft nanites); +1 NV/week more if ingesting inorganic material (hard nanites). Natural degradation **-1 NV/month** (often recycled if not flushed).

### Weekly Resistance

Opposed **Charisma + Willpower + Essence** vs **NV + MEC**. Net hits for the character become a finite **Control Dice Pool** for that week (not a standing bonus).

### Control Test

Simple **Composure (4)**. Fail → lose control for **(4 - hits)d6 hours**. If Control Pool dice or Edge were spent and the test still fails, 6s explode on duration. Minimum **one Control Test/day**; also trigger when:

- >=4 boxes in a single attack (P, S, or mixed)
- >=6 boxes total damage
- Knocked unconscious (CFD personality auto-gains control; use Adrenal Control)
- Forced into Fatigue territory

Cap routine Control Tests around **6/day** plus special triggers. Injured CFD personalities who seize control typically **flee**.

### Machine infection

Device Rating 4+ / Pilot 4+ prime targets; timing plot-based. AIs struggle with hormones/eating/sleeping; e-ghosts adapt faster.

## Slowing / delaying (no true purge)

| Method | Effect |
| --- | --- |
| Hunter-killer nanites | **Worse:** each application **+1 NV** |
| Spells targeting nanites | Drain +2 minimum; often fail (too small / processed) |
| Chemicals | Can hurt soft nanites; hard nanites resist at non-lethal doses |
| Medical nanite extraction | **Halve NV** (min 1); extracted nanites can infect others |
| Combined multi-treatment | Best delay (Pulse + chemicals + blood scrub); duration GM judgment |

| Ability | Rule |

### Lockdown strain highlights

- **First 72 hours** after exposure: virally active (mainstream rules) with different test frequency/side effects.

- **Evolution abilities** (all head cases, GM discretion): see *Lockdown* Game Information.
- **QZ Background Count:** Safe enclaves 0; elsewhere >=1; heavy head-case infestation **>=3**.

## Dark Terrors: CFD treatments (black market)

Two stages: (1) unmount CFD personality, (2) restore host. **Rating 1 per dose;** stack doses before effect for higher Rating.

| Treatment | Avail | Cost/dose |
| --- | --- | --- |
| NanoScrub | 16F | 7,500¥ |
| Overwriter Nanites | 14F | 5,000¥ |

Aerosol Overwriters: Rating halved (round down). NanoScrub: **injection only**.

**Overwriters:** End of each CT: Overwriter Rating x 2 [Rating] vs CFD NV x 2. Net hits reduce opponent Rating/Volume by 1 per net hit until either hits 0. Volume 0 = infection gone. Leftover Overwriters lose 1 Rating/day.

**NanoScrub:** After 1 hour, then each hour: host NV and other nanoware Rating -1; NanoScrub Rating -1 after first hour. Volume 0 = cured. Side effects: roll Rating dice at start. Glitch: destroy head/eye/ear ware with base Essence < (Rating/10). Critical glitch: treatment fails; Monad psychotic; full overwrite in (10 - NV) days (min 1).

Nanohives not destroyed by these; after CFD gone, Matrix-affect normally or infection replenishes (*Lockdown* p. 200).

### Monad Matrix combat (original CFD; not Lockdown Boston strain)

- Mental Attributes as AIs/deckers/TMs; **Matrix Entity Concentration (MEC)** replaces Depth; **Nanite Volume (NV)** replaces Essence
- Home "device" Device Rating = NV; all 4 Matrix attributes; no program slots
- Matrix Init: (NV + Intuition) + 4D6; always hot-sim (+2)
- Core CM: 8 + (MEC / 2); Matrix CM: 8 + (NV / 2); resist both with Willpower + Firewall
- Repair Core: Extended Software + MEC [NV] (1 day), 1 box/hit; Matrix Damage: Hardware Test (SR5 p. 228), NV as toolkit; each repair injury -1 NV
- Core to 0: disrupted; dumpshock others; NV - (1 + unresisted overflow); if overflow would hit 0, permanent death; else dormant (10 - NV, min 1) hours
- Matrix CM to 0: permanent destruction; host Mental Attributes current and max reduced by (NV / 4) round down
- Format Device: Monads add Nanite Rating to defense pool; repair boot sector = Complex Actions = net hits (no roll); reboot without repair = destroyed as Core overflow
- Cannot Control Device / Spoof Command nanites independently

**Technomancer: Defrag Echo**

- Grants **Unmount AI/Monad** Resonance Action
- Also: increase 1s needed to glitch by (Submersion Grade / 3) on up to 1 + Submersion Grade PANs; needs mark or sustained complex form; start within 100 m

**Unmount AI/Monad:** Need Matrix connectivity or temp residence device. Roll Charisma + Willpower, or Decompiling + Resonance + Willpower. AI resists Depth x 2; Monad resists MEC x 2. Net hits = Depth or MEC = success (ejected to Matrix). Fade: 2 DV per hit (not net) on target's Depth/MEC roll, minimum 2.

**Other methods / survivors:** FastJack remits CFD (no tests); social talk-down penalties; survivors often Blank Slate (*Chrome Flesh* p. 57); personafix / Mind Realms restoration; or Amnesia / Flashbacks / Phobia etc.

## Lockdown strain: Evolution abilities

All head cases (GM discretion):

| Ability | Rule |
| --- | --- |
| Faster Healing | Healing Tests every 5 min (Stun) / 2 h (Physical); add NV. Need 1 kg animal flesh per CM box healed |
| Rapid Healing | Spend 1 Body or Strength; pool (original Attribute x 10) Physical boxes to repair. Heal up to NV boxes/IP for 4 IPs. Replenish spent attrs by eating 10 kg protein + Healing Tests vs attr loss |
| Damage Resistance | Physical damage immediately reduced by 1/2 NV (round down). Stun unaffected. Electricity overcomes; after Stun fills, Electricity overflow Physical is not reduced |
| No Wound Too Great | Nanites can rebuild even face; Electricity shorts nanites during repair (Damage Resistance off) and often kills host |

Original personality remains tortured passenger inside the mind.
