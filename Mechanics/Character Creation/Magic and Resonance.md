## Chargen procedure

1. Assign Mag/Res Priority (not E) matching path.
2. Record Priority **Magic** or **Resonance** rating.
3. Add Metatype **special Attr points** to Edge and/or Mag/Res (stack on Priority rating).
4. Choose **tradition** (if magician / mystic adept / aspected spellcaster path).
5. If aspected: lock **one** Magical skill group.
6. Take **free** skills / spells / forms / Active skill / skill group from Priority row.
7. Adept: spend PP = Magic on powers. Mystic adept: buy PP later with Karma (5 each, ≤ Magic).
8. More spells/forms/spirits/sprites/foci with leftover Karma (caps below).
9. **No** initiation or submersion at creation unless **Prime Runner** play level.

## Power Points

| Type | At creation | Later |
| --- | --- | --- |
| Adept | Free PP = **Magic** | +1 PP when Magic increases; or Initiation instead of metamagic |
| Mystic Adept | **5 Karma** per full PP; max PP = Magic | No free PP on Magic increase (Core) |

If Magic drops from Essence loss, adept loses equal PP (must drop powers to match). Magic 0 → cut off from mystic abilities.

## Essence loss → Magic / Resonance

| Rule | Detail |
| --- | --- |
| Trigger | Cyberware / bioware (etc.) reduces Essence |
| First loss | Any drop below 6.0 costs **-1** Magic or Resonance |
| Further | Another -1 each time Essence drops below the next lower whole (below 5.0, 4.0, …) |
| Example | Essence 6.0→5.5: Mag -1. Then 5.5→5.0: no further Mag loss. Below 5.0: Mag -1 again |
| Adept | Also lose PP equal to Magic lost |

## Spells / rituals / preparations / complex forms

### Free from Priority

Counts in Priority Mag/Res cells (e.g. A magician: 10 spells/rituals/preparations). Already paid.

### Additional with Karma (creation)

| Item | Karma | Creation cap |
| --- | --- | --- |
| Spell (or ritual / preparation formula) | 5 each | **Each** group ≤ **Magic × 2** (Priority free counts count toward the caps) |
| Complex form | 4 each | Total ≤ **Resonance × 2** (Priority free counts count) |
| Bound spirit | 1 per service (Force = Magic) | Number ≤ Charisma |
| Registered sprite | 1 per task (Level = Resonance) | Number ≤ Charisma |
| Bond foci | per focus rules | Total Force bonded ≤ **Magic × 2** |

Magician / aspected / mystic adept: Magic × 2 is **per formulae group** (spells, rituals, preparations separately). Priority free picks count toward those caps. (The Additional Purchases table wording is compressed; Magic User Types sidebar is authoritative.)
