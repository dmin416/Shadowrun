# Magic and Resonance

Only take this if your Magic/Resonance priority is **not E** (mundane).

## Paths

| Path | Notes |
| --- | --- |
| **Magician** | Full spellcasting, summoning, astral perception/projection (per tradition) |
| **Mystic Adept** | Spells + adept powers; Power Points purchased with karma at creation (Core) |
| **Adept** | Adept powers only; no spellcasting |
| **Aspected Magician** | One aspect: Sorcery, Conjuring, or Enchanting |
| **Technomancer** | Resonance, living persona, complex forms, sprites — not Magic |

## At creation

1. Set **Magic** or **Resonance** from priority + special attribute points.
2. Choose **tradition** (Hermetic, Shamanic, etc.) if Awakened — linked attribute for drain.
3. Select free **spells** or **complex forms** granted by priority (ratings as listed).
4. Adepts spend **Power Points** equal to Magic on powers.
5. Buy foci, fetish, lodge materials, or living persona gear with Resources.
6. Remember: Essence loss lowers Magic/Resonance.

## Drain and fading (preview)

- Spellcasters resist **Drain** with tradition attributes.
- Technomancers resist **Fading** from complex forms.
- Overcasting / overclocking raises force and risk.

See [Magic Basics](../Magic%20Basics.md) and [Matrix Basics](../Matrix%20Basics.md) for play procedures.

## Mundanes

Priority **E** in Magic/Resonance means no Magic/Resonance attribute. You can still buy foci for others, use mundane tech, and take Magic-related negative qualities only with GM care.
