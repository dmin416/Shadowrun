### Addiction levels

| Level | Karma | Craving | Withdrawal (fail) | Extra |
| --- | --- | --- | --- | --- |
| Mild | 4 | ~monthly; 1 dose / 1 hr | -2 Mental **or** Physical attr tests | |
| Moderate | 9 | ~biweekly; 1 dose / 1 hr | -4 Mental or Physical | |
| Severe | 20 | weekly; 2 doses / 2 hrs | -4 Mental or Physical | -2 Social always |
| Burnout | 25 | daily; 3 doses / 3 hrs min | -6 Mental or Physical | -3 Social always |

Physiological vs psychological chooses which Attr-based tests take the penalty. Progression/treatment: Addiction rules p.414.

## Chargen-only / restrictions (quick)

| Quality | Restriction |
| --- | --- |
| Bilingual | **Chargen-only** |
| Aptitude / Exceptional Attribute / Lucky / Incompetent | Once each (Lucky vs Exceptional mutually exclusive) |
| Astral Chameleon / Astral Beacon / Mentor / Spirit Affinity / Spirit Bane | Magic (as noted) |
| Magical Resistance | No Magic rating |
| Focused Concentration | Spellcaster or technomancer |
| Human-Looking | Elf, dwarf, ork |
| Elf Poser | Human |
| Ork Poser | Human or elf |
| Codeslinger / Codeblock | Matrix action with a test |
| Blandness vs Distinctive Style | Incompatible |
| Weak Immune System | Blocks Natural Immunity and Resistance to Pathogens/Toxins |
| High Pain Tolerance | Not with listed pain-mitigation ware/powers |
| Scorched | BTL path needs Mild+ Addiction + gear; IC path needs decker/TM |
