# Qualities

**Positive qualities** cost Karma. **Negative qualities** give Karma back. Net Karma after qualities feeds leftover advancement at creation.

## Budget (Core typical)

- Characters receive a Karma pool at creation (commonly **25 Karma** after priorities — confirm with your Core printing / house rules).
- Negative qualities are capped (often **−25 Karma** worth).
- Positive qualities limited by remaining Karma.

## Positive quality examples

| Quality | Idea |
| --- | --- |
| **Ambidextrous** | Ignore off-hand penalties |
| **Exceptional Attribute** | Raise one attribute max |
| **Natural Athlete** | Bonus to Athletics |
| **Toughness** | Extra damage resistance |
| **Analytical Mind** | Logic/problem bonuses |
| **Home Ground** | Bonus in a defined turf |
| **Lucky** | Extra Edge |

## Negative quality examples

| Quality | Idea |
| --- | --- |
| **Addiction** | Substance or behavior dependency |
| **Allergy** | Common / uncommon triggers |
| **Bad Luck** | Edge complications |
| **Code of Honor** | Behavioral restrictions |
| **Dependents** | People who need you |
| **Enemy** | Named opposition |
| **SINner** | Criminal or corporate SIN baggage |
| **Weak Immune System** | Disease vulnerability |

## Design tips

- Negatives should create **play**, not only free points.
- Match qualities to concept (SINner corp brat, Addiction to jazz, Code against killing innocents).
- Expanded lists: *Run Faster*, *Chrome Flesh*, etc.

## In play

Some qualities trigger tests, lifestyle costs, or plot hooks. Track Addiction ratings, Enemy force, and SINner heat.
