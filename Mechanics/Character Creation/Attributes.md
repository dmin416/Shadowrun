## Inventory (completeness checklist)

- [x] Spend all Attr points; 1 point = +1 from metatype min
- [x] One Mental/Physical at natural max; special attrs exempt
- [x] Augmented max +4 all sources
- [x] Exceptional Attribute / Lucky interactions
- [x] Ware does not raise Knowledge/contact free pools
- [x] Living Persona / astral attrs pointer

## Schema

| Term | Meaning |
| --- | --- |
| Natural rating | Attr after racial min + chargen/Karma raises, before ware/powers |
| Natural maximum | Metatype max (table) |
| Augmented rating | Natural + bonuses (ware, magic, etc.) |
| Augmented maximum | Natural maximum **+ 4** (unless a rule excepts) |

## Attribute list

### Physical

| Attr | Play use (summary) |
| --- | --- |
| Body (BOD) | Condition Monitor; damage/toxin/disease resistance |
| Agility (AGI) | Combat skill link; sneaking; many physical Active skills |
| Reaction (REA) | Initiative; Defense; vehicle Reaction |
| Strength (STR) | Melee DV; lift/carry; some athletic skills |

### Mental

| Attr | Play use (summary) |
| --- | --- |
| Willpower (WIL) | Stun Monitor; Drain/Fading resist (with tradition/Resonance); composure |
| Logic (LOG) | Technical/Matrix skills; Mental Limit; hermetic Drain (with Wil) |
| Intuition (INT) | Initiative; Perception; surprise; Mental Limit |
| Charisma (CHA) | Social skills; Social Limit; shamanic Drain (with Wil); contacts free Karma |

### Special

| Attr | Chargen / play |
| --- | --- |
| Essence (ESS) | Start **6**. Reduced by cyber/bioware. Social Limit uses Essence (round **up**). Mag/Res loss when Essence drops (Magic and Resonance) |
| Edge (EDG) | Luck points; [Edge](../Edge.md). Start at metatype min |
| Magic (MAG) | Awakened only. Start 0 + Priority + special points |
| Resonance (RES) | Technomancer only. Start 0 + Priority + special points |

## Attributes-column spend (Priority)

| Rule | Detail |
| --- | --- |
| Pool | Priority Attributes number (24 / 20 / 16 / 14 / 12) |
| Baseline | Each Physical/Mental attr starts at racial **minimum** (free) |
| Cost | **1 point → +1** rating |
| Must spend | **All** points at creation; cannot bank or convert |
| Cannot buy | Edge, Magic, Resonance, Essence (not from this pool) |
| Caps | Cannot exceed racial **natural maximum** (unless Exceptional Attribute / similar) |

### Natural maximum rule (chargen)

| Rule | Detail |
| --- | --- |
| Limit | At most **one** Mental or Physical attribute at its natural maximum |
| Exempt | Edge, Magic, Resonance (may all be at max if points allow) |
| Exceptional Attribute | With GM approval: one Attr may be **natural max + 1**; still counts as the “at max” slot; costs quality Karma + attr points/Karma to reach |

### Special attribute points (Metatype Priority)

| Rule | Detail |
| --- | --- |
| Source | Metatype column only (Human (9), etc.) |
| Spend on | Edge and/or Magic and/or Resonance **only** |
| Edge start | Raise from metatype Edge **minimum** |
| Mag/Res start | From **0**, then Priority Mag/Res rating, then add special points |
| Unused | Lost after chargen |
| Zero cells | e.g. Troll Priority B (0): raise specials with Karma only |

### Human Edge

| Rule | Detail |
| --- | --- |
| Max | Human Edge natural max **7**; other metatypes **6** |
| Lucky quality | Allows Edge max +1 above metatype max (does not auto-raise; still pay points/Karma). Cannot combine with Exceptional Attribute |

### Exceptional Attribute vs Lucky

| Quality | Effect |
| --- | --- |
| Exceptional Attribute | One Attr (incl. Magic/Resonance, **not** Edge) natural max +1. Once. GM approval |
| Lucky | Edge natural max +1. Once. GM approval. Not with Exceptional Attribute |

---

## Augmented maximum (+4)

| Rule | Detail |
| --- | --- |
| Cap | From **all** sources combined, bonus to any Mental/Physical attr ≤ **+4** over natural unaugmented |
| Sources | Cyberware, bioware, adept powers, spells, drugs, etc. (unless a print exception) |
| Track | List natural and augmented (e.g. Reaction 3 (5)) |
| Chargen | Still respect Avail / Device Rating / Essence |

---

## Ware vs derived free pools

| Calculation | Uses |
| --- | --- |
| Free Knowledge/Language points | **Unaugmented** Intuition + Logic |
| Free contact Karma | **Unaugmented** Charisma × 3 (×6 Prime) |
| Initiative, Limits, Condition Monitors | **Include** augmentation bonuses (Final Calculations) |
| Social Limit Essence | Round current Essence **up** to whole number first |
