# Attributes

## Physical

| Attribute | Used for |
| --- | --- |
| **Body** | Damage track size, toughness, some resistance tests |
| **Agility** | Shooting, sneaking, many athletic actions |
| **Reaction** | Initiative, defense, driving reactions |
| **Strength** | Melee damage, lifting, climbing, some limits |

## Mental

| Attribute | Used for |
| --- | --- |
| **Willpower** | Stun track, drain, composure, magical defense |
| **Logic** | Hacking, technical skills, Mental limit |
| **Intuition** | Initiative, perception, surprise, astral |
| **Charisma** | Social skills, summoning (some traditions), Social limit |

## Special

| Attribute | Used for |
| --- | --- |
| **Essence** | Starts at 6; cyber/bioware reduces it; affects Magic/Resonance and Social limit |
| **Magic** | Awakened power; drops with Essence loss |
| **Resonance** | Technomancers; drops with Essence loss |
| **Edge** | Luck spends; see [Edge](../Edge.md) |

## Spending attribute points

- Priority gives a pool of points for **standard attributes** (Body through Charisma).
- Ratings must stay between racial **minimum** and **maximum**.
- Only **one** attribute may start at the racial maximum (Core rule) — others at least 1 below max unless a quality says otherwise.
- Special attributes use Metatype points (and Magic/Resonance priority), not the main attribute pool.

## Augmented maximums

Cyberware, adept powers, spells, and drugs can raise attributes temporarily or permanently, usually capped at **racial maximum + 4** (augmented max). Track natural vs augmented separately.
