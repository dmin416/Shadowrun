# Skills (Character Creation)

Skills come from the Skills priority as **individual skill points** and **skill group points**.

## Buying skills

- Skill groups cost group points; raise all skills in the group together.
- Individual skills use skill points.
- You generally cannot buy a skill as both group and individual at creation in conflicting ways — follow Core packing rules.
- **Specializations** (+2 to a narrow use) cost 1 skill point each at creation (typical).
- Maximum active skill rating at creation is usually **6** (or 7 with qualities / exceptional rules).

## Skill categories (Active)

Examples — not exhaustive:

| Category | Examples |
| --- | --- |
| Combat | Pistols, Automatics, Longarms, Blades, Clubs, Unarmed Combat |
| Physical | Athletics group, Sneaking, Escape Artist, Free Fall |
| Social | Influence group, Con, Intimidation, Leadership, Etiquette |
| Magical | Spellcasting, Counterspelling, Summoning, Binding, Astral Combat |
| Technical | Cybercombat, Hacking, Electronic Warfare, Hardware, Software |
| Vehicle | Pilot Ground Craft, Pilot Aircraft, Gunnery |
| Resonance | Compiling, Registering, Software (technomancer uses) |

## Knowledge & Language skills

- Free Knowledge/Language points based on Intuition + Logic (Core formula).
- Street, Academic, Professional, Interest knowledge skills.
- Languages have ratings; native language is free / special.

## Linked attributes

Every Active skill links to an Attribute for dice pools (e.g., Pistols + Agility). Check the skill list when planning attributes.

## After creation

Improve skills with **Karma** (cost rises with rating). Specializations and new skills are post-gen advancement options.
