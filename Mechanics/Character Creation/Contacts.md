## Inventory (completeness checklist)

- [x] Free Karma Cha×3 (×6 Prime); Connection + Loyalty min 1 each
- [x] Cost 1 Karma per rating; ≤7 Karma per contact at chargen
- [x] Loyalty bands; Connection use pointer to social chapter

## Schema

| Token | Meaning |
| --- | --- |
| Connection | Reach / influence (chargen max 6; play scale to 12) |
| Loyalty | Trust / how far they'll go for you (1-6) |
| Free contact Karma | Separate pool: unaugmented Cha × 3 (× 6 Prime); contacts only |
| Favor Rating | Size of personal favor (1-6); free if ≤ Loyalty |

## Chargen rules

| Rule | Detail |
| --- | --- |
| Free pool | **Unaugmented Charisma × 3** Karma (Experienced / Street default) |
| Prime Runner | **Charisma × 6** instead |
| Spend on | Connection and Loyalty only (not other chargen buys) |
| Extra contacts | May also spend leftover Step Seven Karma on contacts (same rates) |
| Cost | **1 Karma** per Connection point + **1 Karma** per Loyalty point |
| Minimum | Each contact: Connection ≥ **1**, Loyalty ≥ **1** (min **2** Karma) |
| Per-contact cap | ≤ **7** Karma on any one contact at creation |
| Count | No limit on number of contacts |
| Connection start max | ≤ **6** at chargen (Helps and Hindrances) |
| Ware | Augmented Cha does **not** raise free contact Karma |

## Connection Rating (1-12)

Chargen: use 1-6 only. Higher via play.

| Rating | Description |
| --- | --- |
| 1 | Almost no social influence; mainly their Knowledge skills |
| 2 | One or two knowledgeable friends, or minor influence |
| 3 | A few friends; limited influence |
| 4 | Known in a neighborhood; borough mayor / gang leader tier |
| 5 | Moderate influence; city council / low-level small-mid corp exec |
| 6 | State/sprawl connected; mayor/governor, notable fixer, mid corp exec |
| 7 | Large area + considerable influence; often national-corp leadership |
| 8 | Multi-state; state gov or national-corp executive |
| 9 | Continental; mid exec in small national gov or AA |
| 10 | Worldwide significant influence; senior small-gov / AA |
| 11 | Extreme worldwide; mid major-gov / AAA |
| 12 | Global power player; key major-gov / AAA exec |

### Play hooks using Connection

| Use | Mechanic (summary) |
| --- | --- |
| Reach contact | Optional: 2D6 ≥ Connection = available (busier = harder); GM story veto always |
| Networking intro | Contact Etiquette + Cha [Social], threshold = target Conn; + Connection dice |
| Swag (buy/sell) | Contact uses Cha + Negotiation; Connection bonuses Social limit; Availability/Fence as PC would (Street Gear) |
| Gear Availability Test | Contact's Negotiation + Cha; Connection adds to Social limit |
| Fence via contact | Offer **5% × Loyalty** of item value, no questions |
| Quid pro quo cash | Roughly Conn × 100¥ (info) up to Conn × 1,000¥ (goods/services); Loyalty may cut up to Loy × 10% |

## Loyalty Rating (1-6)

| Rating | Band | Description |
| --- | --- | --- |
| 1 | Just Biz | Purely mercenary; no preferential treatment |
| 2 | Regular | Still business; basic mutual respect |
| 3 | Acquaintance | Friendly-ish; small inconveniences OK; won't take a fall |
| 4 | Buddy | Real friendship / solid respect; goes out of their way |
| 5 | Got Your Back | Long trust; backs you in risky situations |
| 6 | Friend for Life | Will go to the wall for each other |

### Play hooks using Loyalty

| Use | Mechanic (summary) |
| --- | --- |
| Negotiate with contact | Loyalty = bonus dice (PC or contact, as applicable) |
| Squeeze / interrogate contact about runners | Loyalty as modifier or threshold (GM) |
| Confidential legwork | Negotiation; + Loyalty dice; may buy dice: +1 per 100 × (7 − Loyalty) ¥ |
| Haggle business service fee | Opposed Negotiation + Cha [Social]; + Loyalty to your pool; ±10% fee per net hit |
| Personal favors | Agree freely if Favor Rating ≤ Loyalty; else Negotiation Opposed |
| Fence payout | 5% × Loyalty of item value |

## Four contact jobs

| Job | What it does |
| --- | --- |
| **Legwork** | Knows answer? Knowledge + linked Attr [Social]. Else Extended Conn + Cha [Social] (interval 1 hour; threshold by difficulty) |
| **Networking** | Arrange meeting with someone you don't know; risk may require convincing first |
| **Swag** | Find buyers/sellers; Availability / Fencing via contact's stats |
| **Favors** | Direct aid: business (paid under table) or personal (Favor Rating) |

### Favor Rating (personal assistance)

| Rating | Examples |
| --- | --- |
| 1 | Minor message delivery; low-level restricted access |
| 2 | Loan gear ≤5,000¥; first-line supervisor corp action |
| 3 | Mid-level restricted access (standard corp lab) |
| 4 | Loan gear ≤50,000¥; middle-manager requisition |
| 5 | High-level security access (FBI, AA HQ, AAA regional) |
| 6 | Major risk: loan gear ≤500,000¥; senior manager / junior exec corp requisition |

Owed favors: repay at least equal Favor Rating; often plot hooks.

## Design tips

- High Conn + low Loy: useful but transactional.
- High Loy + low Conn: tries hard, limited reach.
- Spread free Karma across several contacts unless concept needs one strong bond (still ≤7 Karma each).
- Burning, outing, or getting a contact hurt is story fuel; Loyalty can drop.
