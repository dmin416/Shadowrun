# Character Creation — Overview

SR5 characters are built with the **Priority System**, then polished with karma, gear, contacts, and lifestyle.

## Steps (typical order)

1. **Concept** — role, vibe, team niche (street sam, decker, mage, rigger, face, etc.).
2. **Assign priorities A–E** — Metatype, Attributes, Magic/Resonance, Skills, Resources. See [Priority System](Priority%20System.md).
3. **Choose metatype** — apply special attributes and racial traits. See [Metatype](Metatype.md).
4. **Spend attribute points** — stay within metatype mins/maxes. See [Attributes](Attributes.md).
5. **Magic or Resonance** (if any) — tradition, spells, spirits, complex forms, etc. See [Magic and Resonance](Magic%20and%20Resonance.md).
6. **Buy skills & skill groups** — ratings and specializations. See [Skills](Skills.md).
7. **Spend resources** — nuyen on gear, cyber, vehicles, lifestyle. See [Resources and Gear](Resources%20and%20Gear.md).
8. **Qualities** — positive and negative (karma balance). See [Qualities](Qualities.md).
9. **Contacts** — Connection + Loyalty. See [Contacts](Contacts.md).
10. **Finishing** — Knowledge/Language skills, final karma spends, derived values, story. See [Finishing Touches](Finishing%20Touches.md).

## Derived values to calculate

- **Initiative** = Intuition + Reaction (+ modifiers / forms)
- **Initiative Dice** = 1d6 base (more with wired reflexes, magic, etc.)
- **Limits** — Mental, Physical, Social
- **Condition Monitors** — Physical and Stun boxes from Body / Willpower
- **Essence** — starts 6; reduced by cyber/bioware
- **Magic / Resonance** — reduced by Essence loss if Awakened / Emerged

## Playability checklist

- Can the character contribute on a run without one niche only?
- Gear Availability within starting limits?
- Lifestyle and fake SIN story make sense?
- Team coverage: combat, Matrix, magic, social, wheels?
