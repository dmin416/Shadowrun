## Assignment rules

| Rule | Detail |
| --- | --- |
| Columns | Metatype · Attributes · Magic or Resonance · Skills · Resources |
| Letters | Assign **A, B, C, D, E** each **exactly once** (one letter per column) |
| No duplicates | Cannot put two columns on the same letter |
| Higher = better | A best, E worst for that column |
| After table | Spend points / apply freebies per column rules below; polish with Karma (Overview Step 7) |

Mundane / non-techno: put **Magic or Resonance** on **E** (dash = nothing).

## Column: Metatype

| Rule | Detail |
| --- | --- |
| Racial mins/maxes | Metatype Attribute Table → [Metatype](Metatype.md) |
| Edge start | Metatype table min (human **2**, others **1**). Magic/Resonance start **0** |
| Special Attr points | Spend **only** on Edge, Magic, and/or Resonance. Never on Mental/Physical |
| Split | Any split allowed among those specials |
| Unused | Points left unspent after chargen are **lost** |
| Zero-point rows | e.g. Troll B (0), Ork C (0), Elf D (0): raise specials later with Karma only |
| Max Edge | Most metatypes **6**; **human 7**. Lucky can allow +1 above metatype max (GM) |
| Max Magic/Resonance | Usually **6** at start; Exceptional Attribute can allow 7 (not Edge; use Lucky for Edge) |
| Stack with Mag/Res Priority | Priority sets Mag/Res rating; **add** special Attr points on top (example: Priority Resonance 4 + 2 special pts → Resonance 6) |

## Column: Magic or Resonance

Freebies from this column are **already paid** (no skill points / no Karma for those listed skills/spells/forms). Pick options that match your type. May buy more later with Karma (caps in Overview / Finishing Touches).

### Type capability summary (Core)

| Type | Project | Perceive | Skill groups | Notes |
| --- | --- | --- | --- | --- |
| Adept | No | Only with Astral Perception power | **Cannot** take Sorcery/Conjuring/Enchanting | PP = Magic (free) |
| Magician | Yes | Yes | Any Magical | Spells/rituals/preps each ≤ Magic × 2 at creation (max known) |
| Aspected Magician | No | Yes | **One** of Sorcery / Conjuring / Enchanting only; never the other two (chargen or later) | Same Magic×2 formulae caps if spellcasting path |
| Mystic Adept | No | If buy Astral Perception power | Enchanting / Sorcery / Conjuring OK | Spells as magician; **PP cost 5 Karma each**, max PP = Magic |
| Technomancer | - | - | Resonance skills; Priority free skills from Resonance / Electronics / Cracking groups | Living Persona later |

## Column: Skills

| Token | Meaning |
| --- | --- |
| First number | Points for **individual** skills (usually Active; can buy Knowledge/Language too) |
| Second number | Points for **skill groups** only |

| Rule | Detail |
| --- | --- |
| Buy rate | 1 point → new skill at 1 **or** +1 rating |
| Groups | Buying a group gives all skills in group at that group rating. Group points **≠** individual points (no convert) |
| No break at Step 5 | Cannot break a group or specialize inside a group during priority skill spend. Break/specialize group skills only in leftover Karma (Step 7) |
| Max at chargen | Skill or group ≤ **6** (skill ≤ **7** with Aptitude). Groups never get Aptitude 7 |
| Spend all | All skill and group points must be spent at creation |
| No duplicate | Do not buy an individual skill already covered by a taken group |
| Specialization | **1 skill point**; +2 DP in subset; **one** specialization per skill at chargen from points; **not** on skill groups |
| Free Knowledge | Separate: **(Int + Log) × 2** free Knowledge/Language points + 1 native Language **N** ([Skills](Skills.md) / Overview) |
| Mag/Res free skills | From Mag/Res column do **not** cost these points |
