# Vehicles

Vehicles and drones use **Pilot** skills, **Handling**, **Speed**, **Acceleration**, **Body**, **Armor**, and **Pilot** autosoft ratings (for drones).

## Basic vehicle actions

| Action | Notes |
| --- | --- |
| **Control Vehicle** | Complex or as listed; keep it on the road |
| **Use Sensors** | Perception with vehicle sensors |
| **Ramming** | Attack using Pilot + Handling vs target |
| **Boarding / bailing** | Timing and speed matter |
| **Gunnery** | Vehicle-mounted weapons; often Logic or Agility linked per rules / control method |

## Chase combat

- Opposed Pilot + Reaction (or Handling-limited) tests
- Speed and Handling modify who can catch whom
- Terrain and traffic set thresholds / modifiers
- Passengers may shoot, cast, or hack while the driver Pilots

## Damage to vehicles

- Vehicles have Condition Monitors; Armor resists DV similarly to characters.
- Track Mobility, Sensors, and other damage effects when boxes fill.
- Called shots on tires, windows, engine change outcomes.

## Control methods

| Method | Who |
| --- | --- |
| Manual | Driver with wheel / sticks |
| AR / jumps remotely | Rigger with RCC / cyberdeck / implanted control |
| Rigged (jumped in) | Rigger perceives as the vehicle - see [Rigging Basics](Rigging%20Basics.md) |
| Autopilot | Pilot rating + autosofts; limited initiative / wit |

## Buying & upkeep

- Purchase with Resources / run pay; Availability applies
- Fuel / power, registration, garage Lifestyle add-ons
- Modifications: armor, weapon mounts, smuggling compartments, spoof chips

## GridGuide & legality

Licensed vehicles on GridGuide are tracked. Shadowrides use stolen plates, spoofed tags, or off-grid Barrens roads.
