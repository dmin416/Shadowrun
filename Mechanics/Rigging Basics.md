# Rigging Basics

**Riggers** specialize in vehicles and drones via a **Remote Control Console (RCC)**, control rig implant, and often jumped-in VR.

## Control modes

| Mode | Description |
| --- | --- |
| **Manual** | Old-fashioned driving |
| **Remote control** | AR/VR from RCC; share stats carefully |
| **Jumped in** | Rigger’s mind in the machine; use rigger’s Initiative bonuses / control rig rating |
| **Autopilot** | Drone Pilot + autosofts act semi-independently |

## Drones

- Same vehicle-style attributes; smaller Condition Monitors
- Autosofts: Targeting, Maneuvering, Clearsight, Evasion, etc.
- Swarm tactics and RCC sharing let one rigger run many drones (Noise & sharing limits apply)

## RCC roles

- Share programs / autosofts across slaves
- Fight Noise
- Protect against Matrix attack on the PAN
- Command multiple devices

## In combat

- Drones roll their own Initiative when autonomous
- Jumped-in rigger uses vehicle/drone Initiative rules
- Dumpshock if the connection dies while jumped in

## Gear priorities

Control Rig (implant), RCC, good drones, spoof chips, weapon mounts, and a getaway vehicle. Resources priority **A/B** is common.
