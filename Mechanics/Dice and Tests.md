# Dice and Tests

Shadowrun resolves almost everything with a **dice pool**: Attribute + Skill (plus modifiers), rolled as d6s.

## Hits

- Each die showing **5 or 6** is a **hit**.
- Compare hits to a **threshold** (success test) or to an opponent’s hits (opposed test).

## Common test types

| Type | How it works |
| --- | --- |
| **Success test** | Hits ≥ threshold = success. Extra hits often improve effect. |
| **Opposed test** | Both sides roll; higher net hits wins. Ties usually favor the defender (or status quo). |
| **Extended test** | Accumulate hits over intervals until you reach a high threshold (or fail / give up). |
| **Teamwork test** | Helpers roll first; their hits become bonus dice for the leader (capped). |

## Thresholds (rule of thumb)

| Difficulty | Threshold |
| --- | --- |
| Easy | 1 |
| Average | 2 |
| Hard | 4 |
| Very Hard | 6 |
| Extreme | 8+ |

## Limits

Many rolls are capped by a **Limit** (Mental, Physical, Social, or gear Accuracy / Force / etc.). Hits above the Limit do not count toward success (Edge can ignore Limits — see [Edge](Edge.md)).

| Limit | Typical formula |
| --- | --- |
| **Physical** | (Strength × 2 + Body + Reaction) ÷ 3 |
| **Mental** | (Logic × 2 + Intuition + Willpower) ÷ 3 |
| **Social** | (Charisma × 2 + Willpower + Essence) ÷ 3 |

## Glitches

- Count **1s**. If 1s ≥ half the dice pool → **glitch** (complication even on success).
- Glitch with **zero hits** → **critical glitch** (serious failure / disaster).

## Modifiers

Apply situational dice pool modifiers (visibility, wound penalties, distraction, tools, assistance). Always note wound modifiers from Physical and Stun damage tracks.
