# Edge

**Edge** is luck, grit, and narrative favor. It is spent and usually refreshes between sessions (or when the GM awards it).

## Spending Edge (common uses)

| Use | Effect |
| --- | --- |
| **Push the Limit** | Add Edge rating in dice *and* ignore Limits for that test; 6s explode (rule of six). |
| **Second Chance** | Reroll all failed dice on a test (not 1s that already “failed”). |
| **Seize the Initiative** | Go first in the initiative pass (or jump to top of order — per table ruling). |
| **Blitz** | Roll initiative with maximum dice (edge rating added appropriately per rules). |
| **Close Call** | Negate a glitch / critical glitch, or reduce critical damage outcome. |
| **Dead Man’s Trigger** | Act briefly when taken out (GM-approved last gasp). |
| **Not Dead Yet** | Avoid death / catastrophic outcome once (GM may require story cost). |

Exact list and wording vary slightly by table; Core Rulebook Edge chapter is authoritative.

## Gaining Edge

- Start with Edge from character creation (metatype + priority / qualities).
- GM awards Edge for clever play, heroics, or plot beats.
- Some qualities and events restore or grant temporary Edge.

## Notes

- Edge spent on a roll is gone until refreshed.
- You generally cannot spend more Edge than you have.
- Edge is one of the strongest levers in SR5 — track it openly.
