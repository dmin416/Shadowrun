# Compiled Augmentation Tables

These are the compiled reference tables from Chrome Flesh's "Compiled Augmentation Tables" chapter (pp. 222-239), gathering every augmentation from Chrome Flesh, the Shadowrun, Fifth Edition core rulebook, and Stolen Souls into one place. The REF column points to a Chrome Flesh page number unless otherwise noted (SR5 = Shadowrun, Fifth Edition core rulebook; Stolen Souls = the Stolen Souls sourcebook).

Values below are transcribed as printed in the compiled tables. Where the print is garbled, blank, or self-contradictory, the cell is left blank or annotated with a `[print quirk: ...]` note, and cross-checked against the SR5 core rulebook or the relevant Chrome Flesh chapter text in this vault (07, 08, 10, 11) where possible. Indented/nested device names (e.g., "Control rig, Rating 1") are flattened to `Parent, Child` naming to preserve the original table's grouping.

*Print quirks noted throughout the chapter:* The column header for COST is misprinted as "C0ST" (zero) on most pages; this is rendered as COST below. The ¥ currency symbol is dropped at several line-wraps (e.g., Control rig Rating 3, Wired reflexes Rating 3); it has been restored below since the underlying value is unambiguous.
