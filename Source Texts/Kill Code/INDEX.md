# Kill Code

Advanced Matrix rules after Data Trails.

## Sections
- **Matrix ops primer**: Sharper guide to hacking play and opposition
- **Decker builds**: More ways to make elite deckers
- **Parallel Processing / Data Streams**: Technomancer streams (sourcerer, technoshaman, machinist, cyberadept)
- **Complex forms, sprites, echoes**: Extra TM tools and qualities
- **Dips and Chips**: New programs, decks, and Matrix gear
- **Null Sign**: Follow-up on Null Sect threats
- **Into the Wild**: Wild hosts with no clear owner
- **Core of Consciousness**: Technocritters, protosapients, Matrix lifeforms
