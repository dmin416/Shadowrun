## Schema

| Col | Meaning |
| --- | --- |
| Src | Core / RnG / SL |
| Skill | Blades · Clubs · Unarmed · Exotic(subtype) · Improvised (GM: Clubs or Unarmed as fits) |
| Acc | Attack limit. `Phys` = Physical limit. `N(M)` = base N, wireless M |
| Reach | Integer; `0` = none; `A/B` = mode-dependent |
| DV | `(STR±N)P/S`, fixed DV, or `(e)` Electricity |
| AP | Armor penetration; `-` = none |
| Avail / Cost | Street Availability / nuyen; `-` = none or included in parent SKU |
| Rules | All per-item mechanical notes (no flavor) |

## Common rules

- Most melee DV = wielder Strength + weapon modifier (P or S as listed). Fixed-DV shock/stun gear uses Electricity damage (Core).
- Acc is the limit on the attack test. Some fist weapons use Physical limit (`Phys`) instead of a fixed Acc.
- Reach is abstract melee length advantage (Core Melee Combat). Higher Reach favors the wielder vs lower Reach.
- Skill is by row. Exotic rows need Exotic Melee Weapon with the listed subtype.
- Ready Weapon defaults to Simple Action. Wireless bonuses apply only while wireless is on.
- Shock/stun charge gear (unless a row overrides): 10 charges; wall recharge 1 charge / 10 seconds; wireless induction recharge 1 charge / hour.
- Core text points improvised melee stats at Melee Combat (p. 184); Core does not print that table. Filled improvised stats are from RnG (included below).
- Cougar Fineblade Acc: use chapter Acc **7**. RnG compiled summary table reprints Acc 6; prefer chapter.
- Cyber implant melee is not duplicated (see Cyberware).

## Shared procedures

### Garrote (RnG; also used by nunchaku choke)

1. Place: attack with Exotic Melee (Garrote) using Called Shot Location; need ≥1 net hit (similar to subduing).
2. Once placed, on a later Action Phase the attacker may deal the weapon’s DV and/or improve the hold with another Attack Test and/or knock the opponent down.
3. Break free: Agility + Unarmed Combat [Physical], threshold = attacker’s net hits on all attacks so far; or Knock Out of Hands / similar grip-breaking attack.

### Victorinox Memory Blade (RnG)

- SmartSteel worn as clothing (belt, bracelet, etc.) that hardens into the weapon.
- Harden or become flexible again: Complex Action, plus the normal Simple Ready/draw when bringing it into play.
- If the grip is concealed as part of the worn form: Concealability −4 to detect the weapon.
- Change shape: Software + Logic [Mental] (8, 1 minute) Extended Test.

### Ash Arms chainsaws (RnG) civilian tools

Combat models are weaponized (safeties stripped for swinging). Non-combat tool versions: Acc 3; DV reduced by 2; Combat chainsaw Avail 2 / 150¥; Monofilament chainsaw Avail 6R / 1,500¥.

### Krime Reaver package (SL)

Troll sizes only. One purchase (300¥) is an entrenching tool usable as prybar / pick / hatchet / hammer / saw, plus three combat modes on separate catalog rows: Axe (Blades), Pick (Blades), Knob (Clubs).

### Krime Gloves package (SL)

One purchase (600¥, Avail 8R) includes knucks mode and stun-pad mode (separate rows). Stormcuff battery: swap like a clip. Available in sizes other than troll (unlike much Krime gear).

### Krime Whammy package (SL)

Troll sizes only. Firearm SKU: shotgun Acc 3, DV 12P, AP −1, mode SS, RC 1, ammo 5(m), Avail 12F, Cost 2,000¥. Standard accessories: melee hardening, shock pad. Shotgun rules: all range penalties doubled; fired rounds are not penetrating weapons vs barriers. Club mode on catalog row; min STR 5. Vs barriers with the hammer portion: Agility + Clubs [Accuracy] or Agility + Strength.
