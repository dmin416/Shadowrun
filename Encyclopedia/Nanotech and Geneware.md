## Nanotechnology rules (CF p.145-147)

### Hard vs soft

- Game terms mostly interchangeable. Soft: partly artificial / genetically modified micro-organisms; better for metabolic / biotech support. Hard: diamondoid nano-drones; modular code; reprogrammable.
- Soft harder to detect: Detection threshold **+2** vs soft (Nanoscanner / clinical). Soft powered by organic processes; look like natural counterparts.

### Essence / grades

- **Nanoware:** no Essence cost; **no grades**.
- **Nanocybernetics:** cyberware (Core p.451); Essence + all grades apply.

### Using nanoware

- Free-floating colonies via blood/lymph/extra-cellular fluid, or organ-local colonies. Delivery: hard = aerosol or injection; soft = injection or ingestion. Active ~**1 minute** after intro.
- Always active unless **nanohive** present (hive enables controlled activation, recovery, downtime storage).
- Not usually permanent without hive: body hostile; flushed/absorbed over time despite protein-matched immune markers.

### Rating and degradation

- Rating = hardiness / versatility / performance.
- Without hive: Rating permanently degrades **−1 per week**.
- Functioning nanohive counters loss (replenish feedstocks/colony) for hard or soft.
- Serious wounds: for every **3** Physical boxes taken, **−1** Rating on any **active** nanoware. Recoverable over time with hive.
- Rating 0 = destroyed; hive can still replenish normally.
- **CFD** sufferer nanoware does **not** degrade.

### Hard nanite reprogramming / Matrix

- Reprogram via body’s conductive tissue using a **hard nanohive**. Changes type to a new hard nanoware. Suspends current ops while receiving instructions. Hive does **not** reduce Rating when reprogramming.
- Hard nanites communicate via conductive tissue / UV; **no Matrix icons**. Indirect hack only via hard nanohive device (has Matrix icon).

### Detection (Nanotech Detection table CF p.153 + Detecting Soft Nanites p.146)

| Type | Threshold |
| --- | --- |
| Nanocyber Standard / Alpha / Beta / Delta | 1 / 2 / 3 / 4 |
| Nanoware Hard / Soft | 2 / 3 |
| CFD Replicators | 5 |

- Test **per system**. Nanoscanner range **1 m**; installable as sensor function (Core p.445).
- **Detecting Soft Nanites:** soft nanite threshold via nanoscanner or clinical tests **+2** (in addition to table Soft 3 unless GM treats table Soft as already incorporating difficulty; printed both ways). Soft machines look like natural counterparts.
- Markers: reduce nanoscanner **dice pool** by marker Rating (separate from threshold).

### Replicators (CFD only; not for sale)

CFD victims only. Build soft/hard nanites from host materials. Camouflaged; Detection 5. Flavor warning only.

## Genetech rules (CF p.155-157)

### Basics

- Gene therapy: nanites / retroviruses / vectors alter DNA; nutrient tank; clean-room vs bio/CFD contamination. Cost includes supplies, hospitalization, tailoring.
- Essence loss from geneware is **permanent** (invasiveness + “foreign nature” / mana disruption). Cannot remove later; **no Essence hole** if later rendered useless. Revitalization cannot restore gene-therapy Essence.
- All genetech permanent unless noted (infusions temporary).

### Genetic restoration

**Rejuvenation maintenance (Leónization / Physical vigor):** one major therapy session, then usually maintenance every **6 months** for the next **3 years**. Limited repeats before cumulative Essence toll. Does not fully stop time: brain chemistry largely unaltered (memory/motor risk); Alzheimer’s/Parkinson’s (connection-based) not corrected by rejuvenation. **Lifespan extension** is age-related but explicitly needs **no** follow-ups.
