## Common rules

### Mounts (Core p.417 + accessories p.431)

- Mounts: **underbarrel**, **barrel**, **top**. One accessory per mount.
- **Integral** accessories (come with weapon) do **not** use mount slots.
- **Hold-outs:** no mounts; cannot take accessories.
- **Pistols, machine pistols, SMGs:** top + barrel only (no underbarrel).
- **Rifles and heavy weapons:** all three mounts.
- Projectile weapons: only accessories designed for them.
- RnG expands slots conceptually to six places: top, underneath, side, internal, barrel, stock. Side/internal/stock used by RnG mods. RnG restates: light pistols top + barrel only; hold-outs none.

### Accessory vs modification (RnG)

- **Accessory:** usually top/under/side; buy and attach. Swap normally ≥ **5 minutes** still (not mid-firefight) unless **Slide mount**.
- **Modification:** or accessory on stock/barrel/internal: more work.
- Cannot double same accessory/mod for double benefit. Same mod in two slots wastes a slot. **One modification per slot.**
- Install knowledge: [Weapon Type Knowledge] + Logic (4) [Mental]; Matrix Search / contacts for plans (+6 dice if plans found). Restricted search threshold ≥3; Forbidden ≥6.
- Tools: kit usually enough for top/under/side accessories; **shop** for internal/barrel/stock mods (unless noted).
- Test: generally Armorer + Logic [Mental] Extended (thresholds/intervals Core p.48 guidelines). SL items often list Slot / Threshold / Duration / Tools / Skill explicitly.

### Recoil compensation stacking (RnG)

Cannot stack listed pairs (also: same accessory twice never stacks):

| Option | Does not stack with |
| --- | --- |
| Bipod | Foregrip, gyro mount, sling, tripod, underbarrel weight |
| Folding stock | Hip pad bracing, shock pad, sling |
| Foregrip | Bipod, gyro mount, tripod, underbarrel weight |
| Gyro mount | Bipod, foregrip, tripod, sling, underbarrel weight |
| Hip pad bracing | Folding stock, shock pad, sling |
| Shock pad | Folding stock, hip pad bracing, shock pad, sling |
| Sling | Bipod, folding stock, gyro mount, hip pad bracing, tripod, underbarrel weight |
| Tripod | Bipod, foregrip, gyro mount, sling, underbarrel weight |

### All About Flamethrowers (RnG p.49; underbarrel uses same)

- Ignite flame: Complex Action; wireless to PAN → Simple; wireless DNI → Free.
- Single target, or **area attack** (Complex): up to **two additional** targets within **2 m** of another target. One Attack Test vs all; separate Defense Tests. DV **−2** per additional target engulfed.
- May use **Suppressive Fire** (Core p.179): consumes **4** shots; may use Flechette Suppressive Fire rules (RnG p.120).
- Fire damage (Core p.171); sets fire to almost everything in AoE for at least a short time (GM discretion).
- Ranges: **Taser** bands, but only **−1** at Extreme; **no** Long-range penalty (or closer).
- Skill: Exotic Ranged Weapon (Flamethrowers).
- **No accessories** on flamethrowers except biometric / Advanced Safety.

**Shiawase Blazer** (typical underbarrel base): Acc 6, DV 10P, AP −6, SA/BF/FA, ammo 4(c), Avail 16F, Cost 2,200¥. Replacing fuel tank: full Combat Turn.
