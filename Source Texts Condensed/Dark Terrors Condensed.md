Full text: [07 - Marooned Spirits](07%20-%20Marooned%20Spirits.md). Builds on Shedim, *Street Grimoire* p. 93.

### Core shedim combat

- Astral form: spectral jellyfish; Energy Drain shows tentacles
- Assensing: host looks gray ghost; peering into body invites Astral Combat; Aura Masking can mask shell
- Physical Attributes get inhabited body's metatype adjustments
- All damage (incl. mana spells) hits body first; fill Physical CM + Overflow, then Regeneration check; spirit forced to astral
- Then destroy on astral (Astral Combat, weapon foci, mana spells) or it flees
- Banishing: start with services = Force; no summoner bonus. After Banishing ejects spirit, Banisher keeps link and may Banishing-test again next Action even if fled
- Optional powers: standard every 3 Force, plus ritual-granted powers below

### New Critter Powers (master rituals)

**Anchored Resident (Bind to Anchor):** On disruption, return to designated object/location instead of home plane. Moving the anchor (ward / other metaplane) can trap them.

**Shell Game (Slippery Soul):** When hopping or when physical form "killed," jump to another shell within **Force x 100 m** instead of ejecting to astral.

**Superior Banishing Resistance (Soul Binding):** Simple Action: Magic + Edge Test, generating services to stay bound to current plane.

**Superior Regeneration (Form Reinforcement):** As Regeneration (SR5 p. 400) plus: extra Regeneration Test as Simple Action once per IP (even unconscious), in addition to free end-of-turn test; heals all damage sources (allergens in contact still block).

**Wounded Fury (Raging Soul):** Bonus Initiative Dice = current injury modifier (no max). Lasts Essence Combat Turns, then unresisted Stun = number of bonus dice until Stun CM full. Recovers naturally; new injury can retrigger.

## 09 - Monads and CFD

**Story/hooks:** Miles Lanier farewell: CFD tide turning but not gone; C5 / Overwriter from Celedyr; NanoScrub Japanacorp push; free clinics in BRA nations (not NAN = smuggling gigs); DSECI; NeoNET AAA collapse / Villiers / Spinrad; Boston Lockdown strain vs original CFD.

Full text: [09 - Monads and CFD](09%20-%20Monads%20and%20CFD.md). Two stages: (1) unmount CFD personality, (2) restore host.

### CFD Treatments (black market dose)

| Name | Avail | Cost |
|---|---|---|
| NanoScrub | 16F | 7,500¥ |
| Overwriter Nanites | 14F | 5,000¥ |

Rating 1 per dose; stack doses before effect for higher Rating. Aerosol Overwriters: Rating halved (round down). NanoScrub injection only.

**Overwriters:** End of each Combat Turn: Overwriter Rating x 2 [Rating] vs CFD Nanite Volume x 2. Net hits reduce opponent Rating/Volume by 1 per net hit until either hits 0. Volume 0 = infection gone. Leftover Overwriters lose 1 Rating/day.

**NanoScrub:** After 1 hour, then each hour: host Nanite Volume and other nanoware Rating -1; NanoScrub Rating -1 after first hour. Volume 0 = cured.  
Side effects: roll Rating dice at start. Glitch: destroy headware/eyeware/earware with base Essence cost < (NanoScrub Rating / 10). Critical glitch: treatment fails; Monad psychotic; full overwrite in (10 - Nanite Volume) days (min 1).  
With Overwriters present when NanoScrub kicks in, Overwriter Rating reduced like other nanoware.

**Nanohives:** Not destroyed by these; after CFD gone, Matrix-affect normally or infection replenishes (*Lockdown* p. 200).

**Hostage heart-stop:** Complex Action: Monad stops heart = 1 box Physical Overflow (accumulates). Medical restart works; Monad must spend another Complex Action to stop again.

**Control Test:** Treated Monad usually attempts takeover (*Lockdown* p. 199) and fights.

### Monad Matrix combat (original CFD; not Lockdown Boston strain)

- Mental Attributes as AIs/deckers/TMs; Matrix Entity Concentration replaces Depth; Nanite Volume replaces Essence
- Home "device" Device Rating = Nanite Volume; all 4 Matrix attributes; no program slots
- Matrix Init: (Nanite Volume + Intuition) + 4D6; always hot-sim (+2)
- Core CM: 8 + (MEC / 2); Matrix CM: 8 + (Nanite Volume / 2); resist both with Willpower + Firewall
- Repair Core: Extended Software + MEC [Nanite Volume] (1 day), 1 box/hit; Matrix Damage: Hardware Test (SR5 p. 228), Nanite Volume as toolkit; each repair injury -1 Nanite Volume
- Core to 0: disrupted; dumpshock others; Nanite Volume - (1 + unresisted overflow); if overflow would hit 0, permanent death; else dormant (10 - Volume, min 1) hours
- Matrix CM to 0: permanent destruction; host Mental Attributes current and max reduced by (Nanite Volume / 4) round down
- Format Device: Monads add Nanite Rating to defense pool; repair boot sector = Complex Actions = net hits (no roll); reboot without repair = destroyed as Core overflow
- Cannot Control Device / Spoof Command nanites independently

### Technomancer: Defrag Echo

- Grants **Unmount AI/Monad** Resonance Action
- Also: increase 1s needed to glitch by (Submersion Grade / 3) on up to 1 + Submersion Grade PANs; needs mark or sustained complex form; start within 100 m

**Unmount AI/Monad:** Need Matrix connectivity or temp residence device. Roll Charisma + Willpower, or Decompiling + Resonance + Willpower. AI resists Depth x 2; Monad resists MEC x 2. Net hits = Depth or MEC = success (ejected to Matrix). Fade: 2 DV per hit (not net) on target's Depth/MEC roll, minimum 2.

### Other methods / survivors

- FastJack Fletcher Bissell AI: remits CFD (no tests); personality captive; may fail when dramatic
- Social talk-down: disastrous-to-self / enemy penalties; no mental Manipulation vs Monads
- Survivors often Blank Slate (*Chrome Flesh* p. 57); personafix / Mind Realms restoration; or Amnesia / Flashbacks / Phobia etc.
- NeoNET collapse: SINless citizens, fake SINs burned, grid/scrip issues; optional SpinGlobal rebrand

Sentient Matrix entities from machine code; hate AI and Emerged; view mundanes as rightful users. Hierarchy: Overseers + Null IC.

**Null IC:** As standard IC (SR5 p. 247) for dice pools / obedience / no personality.

**Null Overseers:** As xenosapient AI (*Data Trails* p. 145) except: part of host; no Emulate needed; can do Node actions for home host from anywhere (with range mods). Instead of Emulation, once/Combat Turn use Depth for one Complex Action:

| Action | Effect |
|---|---|
| Fortify | One deployed IC: Matrix damage reduced by (Depth / 2, round up) DV rest of turn |
| Lingering Mark | EW + Logic [Depth] vs Willpower + Firewall; marks persist (net hits) hours through reboot |
| Target Lock | Target takes -(Depth / 2, round up) to all Matrix Defense rest of turn |
| Rally | All deployed IC Initiative + Depth (once/turn) |
| Reinforce | Load 2 IC in one turn (3 if Depth 6+); then no load for (10 - Depth, min 2) turns |

### Death of a Thousand Cuts (Shimmering Death)

Movement tests every ~10 minutes (or in combat when rate changes):

| Movement | Threshold |
|---|---|
| Walk | Agility (2) |
| Run | Agility (4) |
| Sprint | Agility (6) |

**Failure:** Physical damage. Base starts 1P.  
- Add (threshold - hits) to DV; that sum becomes **new base** DV for future fails (shards accumulate).  
- Also +1 starting DV per subsequent failed test.

**Encumbrance:** Most recent resisted DV acts as negative Agility for movement calc (does not change Move rate; exceeding lowered Agility causes another Damage Resistance). When DV > Agility, compare to Strength + Agility; when DV exceeds Str + Agi, immobilized.

**Removal:** Extended Medicine + Agility [lower of Mental and Physical] (Last DV, 30 minutes).  
Remove shard-covered armor/clothes: Agility (Last DV); fail = Damage Resist (Last DV - hits).  
Unremoved shards restart damage cycle even on home plane.

Other locales: no complete new critter blocks in extract; Mad Plane / Beautiful Death / Hunters' Realm reagents are plot loot / GM-designed from description.
