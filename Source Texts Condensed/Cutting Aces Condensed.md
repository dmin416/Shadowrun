## 09 - The Art of Confidence

**No mechanics.** Technique/lore only. Formal grift rules are in [11 - The Grifting Bible](11%20-%20The%20Grifting%20Bible.md).

### Short con pointers

- **Pig in a Poke:** Sell a bagged “valuable,” hand junk, run before the mark checks.
- **The Gold Brick:** Inflate a worthless prop into a must-buy relic with lies/papers/shills.
- **Bolivian Fire Drill:** Walk like a stressed courier so hierarchy clears your path.
- **Dancing Pig:** Distraction spectacle while a shill lifts/plants.
- **Clip Joint:** VIP/strip upsell that drains cash then muscles the mark out.
- **Melon Drop:** Stage-break a fake precious item into the mark; pressure payment.
- **Fuchi Two-for-One:** Swap corp scrip for a “fat” stick; palm the real stick.
- **Ring Reward:** Lost-ring plant; mark pays reward and never reaches the girl.
- **Dwarven Speedbump:** Fake (or real) vehicle bump for cash/lawsuit/Melon Drop.
- **Murphy Game (White Van):** Sell “hot” goods that are fakes/empties.

### Long con pointers

- **Money Machine / Salted Mine / Chain Letters / Caribbean Bride / Blue Book:** Classic long-game variants (printer, salted claim, pyramid spam, romance catfish, fake gatekeeper).
- **Phony Cures / SINless Winner / Spanish Prisoner / The Badger:** Snake oil, unclaimable lottery, distant-VIP wire fraud, honeypot blackmail.
- **Orichalcum Shuffle / Worried Wally / Trapped Traveler / Naughty Nightingale:** Fake telesma, job-anxiety seminars, tourist-arrest shakedown, faith-healing long con.
- **Tech Support / Fake Handymen / The 5-0 / Vamping:** Phish, pretext theft, corrupt-cop toolkit, predator bait ambush.
- **Dragon Slaying / Kitten Call / The Big Store:** Create-then-sell the threat; underpriced non-delivery; temporary fake front.

## 11 - The Grifting Bible

### Faction Reputation (new rule)

Expands Street Cred / Notoriety / Public Awareness (*SR5* p. 372). Track per Faction; can be negative. Usually apply at end of mission with Karma. Dead men tell no tales. GM discretion; individual NPCs may ignore standing.

**Sample Factions:** Specific gang, corp, city streets, criminal syndicate, social society. Similar Factions are usually enemies; advancing one often sets back its enemies (cumulative).

#### Scoring

| Action | Effect |
|--------|--------|
| Negotiation, bargain kept | +1 |
| Negotiation, bargain not kept | -2 |
| Con, undetected | +1 |
| Short con detected (within 24 hours) | -3 |
| Long con detected (>24 hours) | -5 |
| Long con detected, per additional full week | -1 |
| Intimidation vs Faction member | -1 |
| Injuring Faction member | -2 (not stacked with later kill) |
| Killing Faction member (known/strongly suspected) | -10 per victim |
| Significantly advance Faction goals | +2 |
| Significantly set back Faction goals | -2 |

### Expanded Negotiation

- Both sides satisfied; GM sets opening offer in nuyen (run pay: *SR5* p. 375).
- Each net hit shifts negotiated value by **10%** of opening offer.
- After value is set, may substitute gear/contacts/services for nuyen.

| Offered | Negotiated worth |
|---------|------------------|
| Gear | [Cost + (Cost x Availability x 10%)] / 2 |
| Contacts | Connection x 1,000¥ |
| Service, Active skill | (DP / 4, round up) x 150¥ per hour x hours |
| Service, Knowledge / info | Knowledge DP x 100¥; if none, GM rates 5-12 |

Gear formula for unexpected bargaining chips, not normal purchases.

### Using Con (structured long/short con)

Track **Intel Rating** and **Prop Rating** (start 0). Long Con steps with intervals take at least a full day. GM modifiers for cleverness.

#### Phase One: Preparation

| Step | Long / Short | Test | Effect |
|------|--------------|------|--------|
| Legwork | Optional, Long | Contact legwork (*SR5* p. 387) | +Intel |
| Matrix Searches | Optional, Long | Opposed Matrix Search (not Ext). Target pool table **missing from print**; GM sets. | +Intel |
| Scouting the Target | Mandatory, Long + Short | Perception + Intuition vs Perception + Intuition | Net hits +/- Intel |
| Evaluating the Target | Optional, Long | Psychology (Profiling) + Logic [Intel] vs current Intel (needs Intel > 0) | Net hits +Intel |
| Prop-Building | Optional, Long + Short | Ext Forgery or Artisan + Agility; thresh = 2 x desired Prop; interval 1 day. Early stop: Prop = hits / 2 (round down). | Sets Prop |
| Prop Acquisition | Optional, Long + Short | Buy (*SR5* p. 416) or steal. Default esoteric: Avail = 3 x Prop; Price = Avail x 1,000¥. | Sets Prop |

#### Phase Two: Engage

| Step | Long / Short | Test | Effect |
|------|--------------|------|--------|
| Set the Hook | Mandatory, Long + Short | Con + Cha (+ Prop dice) vs higher of Judge Intentions or Con + Intuition (- Intel to target) | Win: mark buys it. Lose: fail. Tie Long: Reinforce mandatory. Tie Short: target wins. |
| Reinforce the Lie | Optional, Long (mandatory if tied / skeptical) | Con + Cha vs Judge Intentions. Old Intel/Prop no longer apply. | Win: still bought. Lose/tie: mark realizes. |

Re-enter Phase Two whenever discovery threatens.

#### Phase Three: Getaway

| Step | Long / Short | Test | Effect |
|------|--------------|------|--------|
| Graceful Exit | Optional, Long + Short | Con + Cha vs higher of Judge Intentions or Con + Intuition | Win: mark still believes even if evidence appears. Lose/tie: story frays; Phase Two objective still kept. No exit: mark knows something is wrong when you vanish. |

### Using Intimidation (expanded)

- May substitute for Negotiation for one-sided gains: each net hit = something with no reciprocity.
- No clear offer / hard-to-price info: each net hit = **250¥ value** or **one truthful detail**.
- No net hits: fail (usually “frag off”).
- Glitch: lasting grudge; likely later ambush/betrayal.
- Critical glitch: elaborate long-term enemy alliance (destroy/humiliate, not just kill).
- Intimidating Contacts: also *Run Faster* p. 178.
